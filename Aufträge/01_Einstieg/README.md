# 01_Einstieg
.NET 8 SDK oder neuer mit .NET-8-Targeting-Pack. Keine zusätzlichen NuGet-Pakete.
Öffne die .csproj-Datei in Visual Studio/Rider oder diesen Ordner in VS Code.
Terminal im Projektordner: `dotnet build --no-incremental`.
Während Einstieg und Review weder starten noch Analysehilfen verwenden. Zuerst Anforderungen.md und PriceCalculator.cs lesen.
